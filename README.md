## 저장소 구조
```
team-project/
├─ README.md
├─ docs/
│  ├─ team-rules.md
│  ├─ members/
│  │  ├─ member-a.md
│  │  ├─ member-b.md
│  │  └─ ...
│  ├─ topics/
│  │  ├─ topic-1.md
│  │  ├─ topic-2.md
│  │  └─ ...
│  └─ changelog.md
└─ data/
   └─ summary.md
```
- `README.md`: 메인 소개 페이지 + 수정 이력 테이블 + 충돌 유도 포인트
- `docs/team-rules.md`: 팀 규칙
- `docs/members/*.md`: 각자 담당 산출물
- `docs/topics/*.md`: 공동 기능 단위 결과물
- `docs/changelog.md`: 작업 로그
- `data/summary.md`: 최종 요약
